**Open source worth watching**

- [tokentrace](https://github.com/12122J/tokentrace) — automatic session recording for Claude Code and Codex. Every session captures the transcript, token cost, git diff, and a local report with no setup. Ships with a dashboard and an MCP server so you can ask questions about past agent runs from inside Claude Code.

  ```bash
  npm install -g @j___avi/tokentrace
  tt install
  ```

- [tokenwise](https://github.com/12122J/tokenwise) — a control plane for team AI workflows. Write rules and workflow cards once, manage them from a dashboard, and keep every engineer's agent behavior in sync.

- [repo-publication-auditor](https://github.com/12122J/repo-publication-auditor) — native macOS app and CLI that scans private repos for secrets, leaked infra config, personal data, and missing OSS metadata before making them public.
